# Book Nook Hub

Create a modern, clean single-page web application for a Book Club Recommendation Hub. 

The app should have two main sections:

1. An "Add Recommendation" Form:

   - Fields for Book Title (text input)

   - Author (text input)

   - Genre (dropdown select menu with options: Fiction, Non-Fiction, Mystery/Thriller, Sci-Fi/Fantasy, Romance, Biography/History, and Other)

   - An "Add Book" submit button.

2. A "Recommended Books" Display Grid:

   - Shows the books as clean, elegant cards.

   - Each card should clearly display the title, author, and a styled tag/badge for the genre.

   - Include a simple filter dropdown at the top of the grid so users can filter the list by genre, and a search bar to search by title or author.

Technical details:

- Use a cozy, literary aesthetic (warm cream backgrounds, deep slate or charcoal text, and soft accent colors for the genre badges).

- Use local storage to persist the data so that added books stay visible when the page reloads.

- Ensure it is fully responsive and looks great on both mobile phones and desktops.
